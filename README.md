\# Promise-Keeper



An AI meeting prep agent with persistent memory. It saves promises made in

meetings (pasted, recorded or uploaded), detects when they are fulfilled, and

generates a pre-meeting brief. Built with Streamlit, Hindsight memory and an LLM.



\## Run it

1\. pip install -r requirements.txt

2\. Copy .env.example to .env and add your own API keys

3\. streamlit run app.py
